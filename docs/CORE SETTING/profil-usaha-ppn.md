Mengatur identitas usaha adalah langkah pertama yang wajib dilakukan. Identitas ini akan menempel pada halaman Client Area, kop tagihan (Invoice), dan cetakan Voucher Hotspot.

<br />

Langkah-langkah Mengatur Profil Usaha:

1. Masuk ke menu System > Settings.
2. Pada bagian Profil Perusahaan, lengkapi kolom:<br />- Nama Situs / Usaha: (Contoh: Jaya Net)<br />- Alamat Perusahaan: Alamat lengkap kantor/pusat operasional Anda.
3. Mengunggah Logo:<br />- Logo Utama: Akan muncul di halaman login (Secure Access) dan Client Area.<br />- Logo Sekunder: Digunakan untuk tampilan antarmuka lainnya. (Saran: Gunakan gambar berformat transparan/PNG untuk hasil terbaik).
4. Pengaturan Pajak (PPN):<br />- Jika usaha Anda berbadan hukum dan membebankan pajak ke pelanggan, Anda dapat menyalakan toggle VAT Enabled.<br />- Masukkan besaran pajak di kolom Persentase Pajak (Misalnya: 11%). Sistem akan otomatis menambahkannya ke dalam total tagihan.<br />- Jika harga paket internet Anda sudah bersih (flat), biarkan fitur ini dalam keadaan mati (Nonaktif).
5. Klik tombol Simpan.
